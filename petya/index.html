Как добавить новый урок (для папы)
  1. Положи HTML-страницу урока в папку предмета, например fizika/optika.html. Если предмет новый — создай папку (matematika/, chemia/ и т.д.).
  2. Открой этот index.html и найди внизу массив LESSONS в теге <script>.
  3. Добавь один объект — и всё, карточка появится сама:
{
  subject: "fizika",              // ключ предмета (см. SUBJECTS)
  title:   "Оптика",              // заголовок карточки
  desc:    "Линзы, преломление…", // краткое описание (рус.)
  href:    "fizika/optika.html",  // путь к файлу
  lang:    "sk",                  // язык урока: "sk" или "ru"
  date:    "2026-06-10",          // дата (необязательно)
  badge:   "контрольная"          // ярлык (необязательно)
}

Новый предмет добавляется в объект SUBJECTS рядом (ключ → название, иконка-эмодзи и цвет). Предметы без уроков просто не показываются.
